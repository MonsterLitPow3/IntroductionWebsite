Digipet: Control and Pet Mode

電子寵物：控制與寵物模式

Digipet is an interactive electronic pet project integrating STM32 and ESP32 control. It includes two modes: Pet Mode (emotional interaction, status feedback) and Control Mode (sensor control, remote operation). Combined with a web-based control panel, it realizes real-time communication, action response and intelligent interaction.

All-IN-ONE Drone Project

科技研究與虛擬無人機專案

This project focuses on UAV structural design, aerodynamic simulation and 3D virtual drone modeling. Using Blender for full 3D asset creation, mechanical assembly simulation and scene environment building. The research also includes drone flight principle analysis, power system matching and future application prospects in delivery, inspection and aerial photography.
